Depth comes from tone: each layer is one step lighter (app → sidebar → surface → raised) plus a 1px border. One soft shadow on floating islands only; no glows, no gradients. Morph: 500ms cubic-bezier(.32,.72,0,1); instant under reduced motion. Focus: 2px accent.hover ring, 2px offset.

Tokens in code

Three layers: primitives (gray, violet scales) → semantic tokens above → components read only semantic names. Light mode later swaps the semantic layer under [data-theme="light"]. Existing --arden-* variables become aliases so current code keeps working.
