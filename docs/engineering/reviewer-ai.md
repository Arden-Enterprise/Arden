# Reviewer AI

BM04 F-06 and DS-02a cover assistance before publication. The reviewer opens a pending submission under Reviews → Publications and chooses **Run** on the AI review card, announced as “Review with AI”. The card puts its title, description and action in one row.

The panel gives one to three summary points and up to three checks about clarity, consistency, missing context or potentially sensitive content. Each point can cite up to four passages from the submitted snapshot. A PDF source button opens the cited page and highlights its matching passages. Points that cite several pages show one button per page. When the text layer matches only part of the cited text or finds no match, the reader reports it. The reviewer can use the usual decision controls during AI processing or after a failure.

When PDF extraction and display disagree on the order of headings or columns, the reader highlights the longest ordered group of unique, exact lines that covers most of the excerpt. Other lines stay unmarked and the reader reports a partial match on the original page.

Core accepts only the snapshot version ID and content hash from the renderer. The authenticated route `POST /api/v1/organizations/:organizationId/knowledge/reviews/:submissionId/ai-review` reuses the current assigned-review check. It resolves and integrity-checks the stored content, revalidates access before delegating and withholds results if the grant or pending submission changes during inference. Only content submissions are eligible.

The internal Arden-AI route `POST /v1/submission-reviews` checks the snapshot hash and extracts text locally. Core requests `contractVersion: 2` for multiple passages. Arden-AI continues to accept contract 1 for older Core releases. Deploy the compatible Arden-AI service before this Core release. The provider receives bounded page-aware passages with identifiers. Arden-AI resolves those identifiers to source excerpts and rejects unknown or repeated identifiers. Core validates the response against the same snapshot and request. Each response is scoped to the open review, with no persistence, indexing or changes to the reviewer decision. Core emits preparation, service and total duration in a metadata-only completion event.

The feature requires the paired Arden-AI endpoint and per-organization approval for sending text from pending submissions to the configured model provider. Set `ARDEN_REVIEWER_AI_ORGANIZATIONS` in Core to the opted-in organization UUIDs. Leave it empty by default. Enable it after the paired service is deployed. Review supports text documents and text-extractable PDFs up to 32,000 extracted characters. The assistant reports unsupported content instead of silently reviewing a partial snapshot. The feature has no database migration.
