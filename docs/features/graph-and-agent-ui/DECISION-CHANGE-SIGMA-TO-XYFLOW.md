# Decision-change comparison: Replace `Sigma.js + Graphology` with `@xyflow/react` + `d3-hierarchy` / `elkjs` (and resolve `G4`)

- Affected feature/spec IDs and revisions: `F12` (`F12-AC1`–`F12-AC3`), `G4` in [docs/product/README.md](../../product/README.md), [docs/product/graph-ai-and-work.md](../../product/graph-ai-and-work.md), [docs/engineering/technology-guide.md](../../engineering/technology-guide.md) Sections 1 and 9, [docs/engineering/implementation-status.md](../../engineering/implementation-status.md), and [ARDEN_BLUEPRINT.md](../../../ARDEN_BLUEPRINT.md) Section 3 — baseline `origin/staging` `fa4d6fe` (2026-11-26).
- Current decision and rationale: `technology-guide.md` Sections 1 & 9 previously specified `Sigma.js + Graphology` as the planned client graph renderer (never installed or implemented; no `sigma` or `graphology` package exists in `package.json`). Original rationale favored WebGL canvas scalability for large network graphs. Navigation gap `G4` left the default landing screen vs. Graph entry unresolved (`ARDEN_BLUEPRINT.md` described a graph home while [ADR 0022](../../decisions/0022-home-start-page-and-reader-validity.md) established `Home` as the default start page).
- Earlier brainstorm originator (or unknown): Original blueprint / `ARD-50` graph concept recorded by project lead; exact individual attribution for choosing `Sigma.js` specifically is **unknown** in inspected public records.
- Accountable decision owner (or unknown): Requesting project maintainer.
- Actual approval/source evidence: Maintainer explicitly confirmed `@xyflow/react + d3-hierarchy / elkjs` and confirmed dedicated `/graph` routing (preserving `Home` default per `ADR 0022`) + superseding Sigma.js via [ADR 0036](../../decisions/0036-knowledge-graph-and-modular-typed-ui-blocks.md) on 2026-11-26.
- Proposed replacement and reason: Replace `Sigma.js + Graphology` with **`@xyflow/react` + `d3-hierarchy` / lazy `elkjs`** for an interactive, collapsible enterprise tree graph with real React Island card nodes, inline ISO/IEC 38505-1:2026 governance signals, deep filtering, and full keyboard/a11y parity; add `/graph` in the `WORK` sidebar while preserving `Home` (`ADR 0022`) as the default start page.

## Decision request

Replacing `Sigma.js + Graphology` supersedes an accepted technology choice previously recorded in [technology-guide.md](../../engineering/technology-guide.md), and resolving `G4` commits the workspace navigation slot for `Graph` alongside `Home` (`ADR 0022`). Under [specifications.md](../../engineering/rules/specifications.md), changing an accepted direction requires explicit comparison, honest attribution of missing historical owners, and confirmation. Consulting any teammate who originally proposed `Sigma.js` is recommended on the specification/implementation PR if historical rationale beyond large-graph WebGL rendering exists.

## Resolution

- State: **replacement approved** (`v1` specification approved 2026-11-26; implementation not started)
- Actual decision maker, authority, date and evidence: Requesting project maintainer, 2026-11-26, explicit confirmation of `@xyflow/react + d3-hierarchy / elkjs`, dedicated `/graph` route, and asynchronous PR consultation against `origin/staging` `fa4d6fe`.
- Consultation: **asynchronous on PR (approved)** — public records do not identify a separate individual author for the Sigma.js line; team review occurs asynchronously on the specification/implementation PR.
- Precise approved scope and any conditions: Adopt `@xyflow/react` + `d3-hierarchy` + lazy on-demand `elk.bundled.js` for `/graph`, preserve `Home` as default landing (`ADR 0022`), enforce the 500-document / 1,000-edge server payload cap + collapsible branches + `elkjs` main-thread threshold (`<= 250` nodes / `<= 500` edges), measure exact chunk sizes in build verification, and ship a full Outline Treegrid alternative (`< 768px` default & keyboard/SR parity).
- Affected specifications/ADRs/designs/acceptance cases updated: [ADR 0036](../../decisions/0036-knowledge-graph-and-modular-typed-ui-blocks.md), [CAPABILITY-MAP.md](CAPABILITY-MAP.md), [SPEC-knowledge-graph.md](SPEC-knowledge-graph.md), [flow-3-graph-and-agent.md](../../product/flows/flow-3-graph-and-agent.md), [technology-guide.md](../../engineering/technology-guide.md), [ARDEN_BLUEPRINT.md](../../../ARDEN_BLUEPRINT.md), [implementation-status.md](../../engineering/implementation-status.md).
- Supersession and Knowledge record: Supersedes `Sigma.js + Graphology`; paired team record to be synchronized to the private team knowledge repository on authorized branch publication.
- Remaining owner/actions and separately authorized publication: Maintainer review of reconciled `v1-draft-2` specs; separate authorization required before commits, pushes, PRs, migrations, or deployment.
