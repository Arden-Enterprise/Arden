# Arden collection covers

Original illustrations generated for Arden on 12 November 2026 using the built-in
Imagegen tool (not a CLI/API fallback). No FPT/QMS art, company marks or internal
document content was copied. Consumed by `KnowledgeCatalogEditor` (cover choice)
and `KnowledgeLibraryBrowse` (authorized curated collections).

Shared prompt direction: stylized conceptual collection-cover illustration; dark
graphite `#1c1c23`, ivory paper and muted violet `#8b82f6`; tactile paper and matte
ceramic materials; soft studio lighting, centered crop-safe composition; no text,
logos or watermark. Preserve Arden's existing interface, fonts and icon system.

- `employee-handbook.png`: sculptural ivory open-book/paper leaves, abstract
  graphite people and a violet connecting ribbon; people and shared practices.
- `production-handbook.png`: matte graphite server structures, ivory document
  fins and a violet connecting bridge; systems and operations. Different subject,
  same visual family.

Both selected outputs are copied into this workspace; original generation outputs
remain separately preserved. Decorative covers have empty alt text because the
adjacent collection name is the accessible action label.
