# Arden wordmark exploration

Six monochrome wordmark directions for Arden. The product is private organizational memory: people collect knowledge, connect it to current work, and decide what becomes trusted shared guidance.

## Palette

- Warm white: `#F4F3EF`
- Mist: `#D4D5D5`
- Stone grey: `#929698`
- Charcoal: `#242628`

The SVGs use `currentColor` and default to warm white. Set the CSS `color` to any palette value where the SVG is embedded inline. The showcase previews them on charcoal, grey, and warm white backgrounds.

## Directions

1. **Quiet editorial** — a calm, readable serif; suits the long-lived organizational memory idea.
2. **Open humanist** — widely spaced capitals; professional and clear at small sizes.
3. **Soft lowercase** — approachable and product-like without looking playful.
4. **Technical register** — measured monospaced capitals, nodding to source material and provenance.
5. **Archive slab** — sturdier serif lettering, giving the name a more established, dependable character.
6. **Connected linework** — a custom geometric ARDEN drawn as vector paths; links the word to Arden's graph without adding a separate icon.

Directions 1–5 use local system font families as editable concept lettering with custom size, case, spacing, and composition. Direction 6 is drawn directly as vector paths. After a direction is selected, refine its letterforms and convert any font-based lettering to paths before production. No icon is included because the brief asks for a wordmark.

Open `index.html` in a browser to compare the options, change the background, select a direction, and download its SVG.
