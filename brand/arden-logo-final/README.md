# Arden final artwork

**Flux Circle — Equal rhythm spacing, option 2, v15.** Selected on 15 October 2026. [ARD-51](https://linear.app/ardenknowledge/issue/ARD-51/explore-two-simple-arden-logo-directions).

## Choose an asset

| Use | Files |
| --- | --- |
| Primary navy symbol | `arden-logo.svg`, `arden-logo.png` |
| Navy symbol with the Arden name | `arden-lockup.svg`, `arden-lockup.png` |
| Black, white or inherited-colour vectors | `svg/` |
| Black or white transparent PNG exports | `png/` |
| Overview | `preview.png` |

Symbols are 1254 × 1254 PNGs; lockups are 1890 × 558 PNGs. White variants need a dark background. Current-colour SVGs inherit `currentColor` when inlined; an external `<img>` does not inherit the page's text colour. The three cutouts retain their approved geometry.

The Sora lettering is outlined. Retain [Sora-OFL.txt](Sora-OFL.txt) when distributing the lettering and respect its font licence; no font binary is needed for these exports.

[selection.json](selection.json) records the artwork decision. [manifest.json](manifest.json) records SHA-256 hashes and byte sizes. Graphics and licence text are unchanged from the selected source exports. Duplicate navy aliases and historical explorations are omitted from this delivery.

## Integration boundary

This is a reference and export package. It does not replace web/desktop icons, favicons, installers, or the current Island design. Changing shipped branding needs a separate scoped implementation and visual verification following [DESIGN.md](../../DESIGN.md).
